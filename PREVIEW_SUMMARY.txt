                       DEPLOYMENT INSTRUCTIONS

Step 1: Download Files
  └─ All 30 files are in: apnafantasy-website-complete/

Step 2: Upload to Server
  • Upload entire folder to web root
  • Set permissions: 755 for directories, 644 for files
  • Ensure PHP 7.4+ is installed

Step 3: Configure (optional)
  • Edit includes/config.php to customize company details
  • Update COMPANY_NAME, EMAIL, PHONE, ADDRESS, CIN, GST

Step 4: Set Up HTTPS (recommended)
  • Configure SSL certificate on your server
  • Update config.php for HTTPS detection

Step 5: Test
  • Visit index.php in browser
  • Test age verification gate
  • Try each of the 4 games
  • Check responsive design on mobile

Step 6: Launch
  • Website is live and ready!
  • Monitor game analytics
  • Keep software updated
