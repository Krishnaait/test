OPTION A: USE AUTOMATED SCRIPT (EASIEST)
═════════════════════════════════════════════════════════════════════════════

Step 1: Create GitHub Repository
  ➜ Go to https://github.com/new
  ➜ Enter repository name (e.g., "apna-fantasy")
  ➜ Click "Create repository" (DO NOT add README)

Step 2: Run Script
  ➜ Open PowerShell in your project folder
  ➜ Run: Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process
  ➜ Run: .\PUSH_TO_GITHUB.ps1
  ➜ Enter your GitHub username when prompted
  ➜ Enter repository name when prompted
  ➜ Done! 🎉

That's it! The script handles everything automatically.

TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════

❌ "Git is not recognized"
  → Install Git: https://git-scm.com/download/win
  → Restart PowerShell after installation

❌ "Authentication failed"
  → Create Personal Access Token:
    1. Go to GitHub Settings → Developer Settings → Personal Access Tokens
    2. Click "Generate new token"
    3. Select "repo" scope
    4. Copy the token
    5. Paste token when prompted for password

❌ "fatal: remote origin already exists"
  → Run: git remote remove origin
  → Then run the push commands again

❌ "fatal: no changes added to commit"
  → Run: git add .
  → Run: git commit -m "Your message"

❌ "Please tell me who you are"
  → Run: git config user.name "Your Name"
  → Run: git config user.email "your@email.com"
